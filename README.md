# N.P.C. Dreams — русский перевод

Неофициальная русская локализация игры **N.P.C. Dreams** для RPG Maker VX Ace.

Репозиторий содержит исходник перевода, изменённые игровые скрипты, инструменты проверки и локализованную графику. Оригинальная игра сюда не входит.

> [!WARNING]
> Игра предназначена только для совершеннолетних и содержит откровенные сцены.

## Что переведено

- диалоги и сюжетный текст;
- названия и описания предметов, навыков, состояний и других игровых сущностей;
- элементы интерфейса;
- текстовая графика, которую нельзя перевести через игровые данные;
- отдельные игровые скрипты, связанные с отображением русского текста и интерфейсом.

## Что потребуется

1. Оригинальная игра **N.P.C. Dreams** — [страница игры на DLsite](https://www.dlsite.com/maniax/work/=/product_id/RJ338331.html).
2. Архив перевода из раздела [Releases](https://github.com/liraleva-ship-it/N.P.C.-Dreams-/releases/latest).

Версия оригинальной игры должна соответствовать версии, указанной в описании выбранного релиза перевода.

## Установка

1. Скачайте и распакуйте оригинальную игру.
2. На всякий случай сделайте резервную копию папки игры и файлов сохранений `Save*.rvdata2`.
3. Скачайте архив перевода из раздела Releases.
4. Распакуйте содержимое архива в корневую папку игры — туда, где находится `Game.exe`.
5. Подтвердите замену файлов.
6. Запустите игру. Если в архив перевода входит `Loader.exe`, используйте его; иначе запускайте обычный `Game.exe`.

Не распаковывайте перевод в отдельную вложенную папку: каталоги `Data`, `Graphics` и остальные файлы патча должны оказаться рядом с `Game.exe`.

## Обновление перевода

Скачайте новый релиз и повторно распакуйте его поверх игры с заменой файлов. Сохранения обычно можно оставить, но перед обновлением лучше сделать их копию.

## Удаление перевода

Патч заменяет игровые файлы. Для возврата к оригиналу восстановите резервную копию или заново распакуйте чистую игру. Файлы сохранений можно предварительно перенести в безопасное место.

## Сообщить об ошибке

Ошибки перевода и технические проблемы можно оставить в разделе [Issues](https://github.com/liraleva-ship-it/N.P.C.-Dreams-/issues).

Желательно указать:

- точный текст ошибки;
- где она встречается;
- снимок экрана;
- версию перевода;
- версию оригинальной игры.

Для сюжетных ошибок помечайте сообщение как содержащее спойлеры.

## Структура репозитория

```text
Graphics/Damage/                  локализованная графика боевого интерфейса
localization/N.P.C.Dreams.ru.trans
                                  проект перевода Translator++
localization/scripts/game/        скрипты итоговой версии игры
localization/scripts/mod-loader/  инструменты проверки, запускаемые через ModLoader
localization/scripts/tools/       вспомогательные инструменты переводчика
```

Готовые файлы `Data/*.rvdata2` создаются из проекта Translator++ и игровых скриптов, поэтому в основной ветке они не хранятся. В Releases публикуются только файлы, необходимые для установки перевода поверх оригинальной игры.
